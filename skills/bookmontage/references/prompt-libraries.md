# 提示词参考库

## 第一方，优先使用

- [Google DeepMind Veo Prompt Guide](https://deepmind.google/models/veo/prompt-guide/)：Veo 当前官方方法。
- [Google Cloud Veo 3.1 Guide](https://cloud.google.com/blog/products/ai-machine-learning/ultimate-prompting-guide-for-veo-3-1/)：带完整结构与示例。
- [Gemini Omni Manual](https://ai.google.dev/gemini-api/docs/omni)：包含时间码、素材标签与连续编辑。
- [Runway Prompting Guides](https://help.runwayml.com/hc/en-us/sections/23989550580627-Prompting)：按自家模型持续维护。
- [MiniMax H3 Prompt Skill](https://github.com/MiniMax-AI/MiniMax-H3/tree/main/skills/h3-prompt-writing)：可执行的官方提示词结构。

## 社区灵感库

- [Seedance 2 Prompts](https://seedance2prompts.com/)：更新快、案例多，但并非字节官方。
- [Seedance Now Prompts](https://seedancenow.com/seedance-prompts)：偏 Seedance 2.0，须核对发布日期和模型版本。
- [HeyDreaming](https://heydreaming.com/prompts)：偏广告片，可用于构图和商业节奏灵感。

社区提示词只作灵感。每条可复用模板必须记录精确模型版本、日期、任务模式、输入素材和实片；模型大版本更新或超过 90 天未验证时标记为过期。
