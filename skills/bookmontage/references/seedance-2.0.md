# Seedance 2.0

官方资料：[火山方舟提示词指南](https://www.volcengine.com/docs/82379/2222480?lang=zh)、[ByteDance Seed 发布说明](https://seed.bytedance.com/en/blog/seedance-2-0-%E6%AD%A3%E5%BC%8F%E5%8F%91%E5%B8%83)、[ZenMux 原生视频接口](https://zenmux.ai/docs/zh/api/zenmux/generate-videos-native.html)

## 任务先分型

- 文生视频：主体 + 动作 + 环境 + 光影 + 运镜 + 风格 + 声音 + 约束。
- 图生视频：说明图片是首帧、尾帧，还是只负责角色/场景参考。
- 多模态参考：逐一绑定“图片 N / 视频 N / 音频 N”的职责；动作、运镜和特效尽量交给视频参考。
- 编辑与延长：直接指出要修改或延长的视频，不要误写成“参考视频”，以免任务类型混淆。

## 官方指南里的关键原则

- 每次提到主体都保持同一称呼；多主体素材要明确谁是谁。
- 先锁定空间层：人物、场景、相对位置、构图；再写时间层：动作顺序、转场和节奏。
- 空间关系复杂时优先使用分镜图或走位参考，避免用长篇文字硬描述。
- 台词保留原语言，明确说话者、音色与出现时机；声音与可见动作同步描述。

## ZenMux 当前接口

- 模型名 `bytedance/doubao-seedance-2.0`。
- 原生接口公开支持 480p / 720p / 1080p、最长 10 秒和同步音频；这是网关限制，不是原厂模型完整上限。
- 参考图、视频或音频通过 `content` 数组传入，并给出 `role`。

生产时仍采用 Seedance 2.5 手册中的尺度锚点与动作六要素；它们是 BookMontage 的验收方法，不伪装成官方硬规则。
