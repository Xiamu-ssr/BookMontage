# SkyReels V4

资料：[官方论文](https://arxiv.org/abs/2602.21818)、[ZenMux 模型页](https://zenmux.ai/skyreels/skyreels-v4)

SkyReels V4 是视频与音频联合生成、补绘和编辑模型。ZenMux 当前标价约 `$0.12–0.14/秒`。

公开的一手资料以论文和能力说明为主，我没有找到与 MiniMax H3 同等级、可直接照抄的官方提示词手册。因此这里保留为“模型卡”，不把社区经验冒充官方规则。

测试时采用中等长度的自然语言：明确主体、连续动作、镜头运动、声音与结束画面。需要编辑或补绘时必须先核对 ZenMux 是否暴露对应输入字段。
